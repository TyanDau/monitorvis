# monitorvis

#### 介绍
这一个Android系统综合监测工具[ _去下载最新安装包_ ](https://github.com/TyanDau/monitorvis/releases)

 **功能支持：** 
1. winscope窗口跟踪
2. 待扩展

 **使用说明：**
1. 下载下方release安装包用于抓取winscope文件
2. 访问 http://www.winscope.net 分析winscope文件
